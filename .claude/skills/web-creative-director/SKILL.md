# Web Creative Director

Before writing UI code, establish the art direction.

Do not immediately create components.

## Step 1 — Understand the page

Identify:

- audience
- emotional goal
- primary CTA
- single main message
- desired brand perception

## Step 2 — Define one visual concept

Choose one coherent creative direction.

Do not mix multiple styles.

Define:

- typography
- photographic language
- composition
- whitespace
- scale
- contrast
- rhythm
- motion
- interaction

## Step 3 — Build a narrative

A homepage is not a list of sections.

It is a sequence.

Each section must answer why the next section exists.

Use variation in:

- viewport height
- typography scale
- image positioning
- background tone
- alignment
- content density

Avoid repeating the same section component.

## Step 4 — Distinctive design

Avoid default AI-generated UI conventions.

Prefer editorial art direction and intentional composition over reusable SaaS patterns.

Do not use cards unless the content genuinely requires a card metaphor.

## Step 5 — Motion

Choose a small number of hero motion moments.

For scroll storytelling consider:

- pinning
- scrubbed timelines
- text replacement
- mask reveals
- controlled image scaling
- image transitions
- typography transformations
- horizontal progression where appropriate

Motion must never interfere with reading.

## Step 6 — Implementation

Only after the visual direction is clear should components be implemented.

Preserve accessibility, responsiveness and performance.

## A direction is only real if the assets exist

Art direction that depends on photography the project does not have is a mood board, not a plan. Before committing to a concept, look at what is actually in `public/`. When the concept needs an image that does not exist, **say which image is missing and what it should show** — do not substitute a weak stock-looking asset and proceed as if the direction were intact.
